# Text-object queries

Parent: [Concipio](../../../README.md)

These queries map each language's syntax onto one vocabulary of functions,
classes, comments, and calls, which Concipio reads to find declarations
[CPO§T66]. They are copied unchanged from
[nvim-treesitter-textobjects](https://github.com/nvim-treesitter/nvim-treesitter-textobjects),
commit `5c7b0263797dfd1bd6202f2b219f3b53a80b2187`, under the Apache License 2.0 in [LICENSE](LICENSE).
